## 三、三条需要你知道的结论

### 1. 41.3% 的确认率不是查证不足，是数据本身的性质

155 条待确认里绝大多数属于**官方从未设定生日**的天然缺失，而非没查到。已识别的整类无生日清单：

- **东方 Project 全角色**——ZUN 官方从未设定生日，市面上的日期均属同人二设
- **Fate 玉藻系列**——官方统一无生日
- **VOCALOID/AI 娘中非官方企划角色**、整类 NIKKE、BEATLESS
- **原神非自机角色**（魔女会成员艾莉丝、莱茵多特等）——官方生日表未收录
- **Nekopara 除巧克力/香草外的猫娘**——MyAnimeList 上只有这两人有 Birthday 字段
- **大量轻小说配角**——28 个出处散点化，作者本就不设生日

对比可见规律：**游戏角色占比较高的批次确认率明显更高**（精灵批全出自《约会大作战》→ 75%；机娘批多游戏角色 → 38.2%；而轻小说角色集中的吸血鬼、魔女批则在 40%~49%）。

### 2. 数据来源污染严重，已建立黑名单

本轮发现大量"看起来很像官方"的污染数据，已全部拦截并记录在每批清单的「高风险排除」章节：

| 污染类型 | 典型案例 |
|---|---|
| **AI 生成内容站** | Anibase.Net、红袖读书问答站输出带**虚构纪年**的假数据（如「狐妖历 0474年6月23日」） |
| **声优生日混排** | 巴哈姆特「零境交错全角色生日总整理」日期列实为声优生日（"零 9-9"是高桥花林生日） |
| **不可能日期** | 猫耳 FM 给南宫那月标「02月30日」 |
| **手办站编造设定** | MyFigureList 给 Nekopara 椰子编造身高 168cm/18 岁/8-23 生日，与官方「缅因猫、猫龄 1 岁」矛盾 |
| **真人剧条目≠原作** | 百度百科涂山红红条目是《月红篇》电视剧版（杨幂饰），09-12 不可用于动画角色 |

## 六、可复用的方法论（沉淀）

**证据等级**（从强到弱）：
作者亲定 > 官方画师/官号贺图 > 官方设定集·联动活动页 > 官方 Wiki（Fandom / biligame / HoYoLAB / GameKee）> 萌百·百科多源交叉 > 单源（不写入）

**查证要点**：
- 一次检索同作品多角色，按「出处」分组批量推进，效率最高
- 尽量取得「带年份的完整日期」——闰年校验通过的可信度远高于孤立 M-D
- 星座自洽可作交叉验证（如百度标「处女座」而日期在处女座区间 → 加分）
- 生日口径要按作品分别固化：战双取「启动日」、碧蓝取「下水日」、舰 Colle 取「下水日」、鸣潮「出生日期」须与「实装时间」区分、原神看 HoYoLAB 官方生日表
