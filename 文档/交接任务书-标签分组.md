## 一、任务目标

当前「展开标签」把全部高频标签平铺展示，找起来眼花。改为**分组折叠展示**：
点击「展开标签」后，只显示**各组组名**；点击某个组名，才展开该组内的标签。标签点击筛选逻辑不变。
并新增**网页端「分组管理」**：用户在本地服务器模式下可自助调整分组（挪标签、加删组、改名），保存后所有设备生效。

### 3. 渲染逻辑（通用，不写死组数）

- 展开标签后：按 TAG_GROUPS 顺序渲染，**每行一个组名 + 该组标签数**，组内标签默认隐藏；点击组名切换展开/收起该组。
- **空组自动不显示**（该组没有标签时整组隐藏，实现"分组可自动减少"）。
- 「全部」标签、展开/收起开关保留；**删掉现在的"筛选标签…"输入框**。
- 点击标签 → setTag 全局筛选，逻辑不变。
- 高频门槛（≥2次）不变；低频标签仍不进筛选区。
- 分组只影响筛选区展示，**卡片上的标签、搜索、localStorage 数据一律不动**。

### 3.5 以后加标签怎么办（运维约定）

- 加标签照旧：页面表单 tags 输入 / 手动改 DEFAULT_DATA，数据层不因分组改动。
- 新高频标签自动走第 2 节规则落组；规则判断不了的落「其他」。
- 用户不会改代码：新标签落错组时，用户告知后由接手方在字典里挪一行即可（改配置、不改逻辑）；本任务只做展示分组，不包含可视化编辑入口。

### 3.6 手机端优化（加载 + 窄屏布局，一并处理）

**加载（现状已具备，保留并确认生效，勿回退）：**
- 卡片/列表/历史/拼图图片已用 `loading="lazy"`，卡片图带 `decoding="async"`——确认手机端仍生效。
- 手机端滚动性能已用卡片 `content-visibility:auto`——保留。
- 可选加强（低优先）：给卡片 img 加 `width/height` 或 `aspect-ratio` 约束，减少加载后布局抖动。

**窄屏布局（本任务新增）：**
- 标签分组折叠后：组名行在窄屏（≤768px）要能换行/横向滚动，组名+数量不被截断挤碎（参照刚修的生日横幅：关键文字 `white-space:nowrap;flex-shrink:0`，可收缩元素 `min-width:0`+省略号）。
- 顶部按钮区、种族 Tab 现有 `flex-wrap` 换行可用，但窄屏偏挤——可适度压缩按钮内边距/字号（≤768px 媒体查询内处理，不影响桌面端）。
- 原则：桌面端布局不动，手机端改动全部收在 `@media (max-width:768px)` 内。

### 3.7 分组可视化管理（本地服务器模式，网页自助改分组）

**目标**：用户不会改代码，要求在网页上自己调整分组（挪标签、加/删组、改名），保存后所有设备生效。

**实现：**
1. 分组配置独立化：新增服务器端配置文件 `tag-groups.json`；index.html 内置字典作为**默认兜底**。页面加载时先请求 `GET /tag-groups`，有文件则用文件内容覆盖默认字典；无文件则用内置默认。
2. `server.py` 增加两个接口：
   - `GET /tag-groups`：返回当前分组配置 JSON
   - `POST /tag-groups`：保存分组配置（校验合法 JSON、组名≤10字、标签总数≤200，超限拒绝）
3. 页面 tagBar 附近加「⚙️ 分组管理」按钮（**仅服务器模式显示**；纯静态/直接打开 HTML 模式隐藏或提示不可用）：
   - 弹窗列出所有组 + 每组标签
   - 操作：点选标签移入其他组；新增组；重命名组；删除空组
   - 「保存」→ POST 保存 → 立即刷新渲染
4. 自动归类规则不变：字典没有的新高频标签仍按第 2 节规则落组/落「其他」，用户可在管理界面挪到正确组（挪完即持久化）。

### 4. 验收

1. 浏览器打开：点「展开标签」→ 只看到组名+数量（如"外貌特征 13"），点组名展开组内标签，再点收起。
2. 有空组时不显示该组名。
3. 新增一个高频标签（如给某角色加 tags:"双色瞳"）→ 展开后自动出现在对应组（外貌特征）或"其他"。
4. 点任意标签 → 筛选正常；再点「全部」恢复。
5. 卡片上标签、搜索、详情弹窗不受影响；localStorage 旧数据不冲突（纯 UI 改动，不动数据、可考虑不升 DATA_VERSION，但改完让用户强刷一次页面）。
6. 用浏览器 DevTools 确认无 JS 报错。
7. 手机浏览器（或窗口拉窄到 ≤768px）实测：分组折叠可用、组名不挤碎、顶部按钮/种族 Tab 不溢出、图片懒加载仍生效。
8. 服务器模式：打开「分组管理」→ 把某标签从一组挪到另一组 → 保存 → 刷新页面（或另一台设备访问）分组为新结果；重启 server.py 后不丢失。
9. 无服务器（直接打开 HTML）时：管理按钮不显示或提示"仅服务器模式可用"，页面分组功能正常。
